# Project Rules

- Frontend is Angular 22: standalone components, signals, reactive forms, lazy routes. Follow the angular-developer skill.
- Backend is Spring Boot, package `com.sara.backend`, layers: controller, service, repository, entity, dto. No Lombok.
- Never commit or push. Never open `application*.properties` or `.env`.
- Do small changes only. Show a diff and wait for my review.
- A child component lives in a subfolder of its parent component.
